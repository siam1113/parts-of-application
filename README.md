# Parts of Application

A collection of standalone, reusable UI parts extracted from larger applications, so they can be reused or referenced independently.

## Contents

- `copy-to-clipboard/` — a self-contained "copy to clipboard" component
- `slack-message-input/` — a self-contained Slack-style message input component

## Purpose

Each folder is an independent HTML component that can be opened directly in a browser or copied into another project.
